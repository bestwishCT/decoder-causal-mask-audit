5: 3.1 Encoder and Decoder Stacks
6: Encoder: The encoder is composed of a stack of N = 6 identical layers. Each layer has two
7: sub-layers. The first is a multi-head self-attention mechanism, and the second is a simple, position-
8: wise fully connected feed-forward network. We employ a residual connection [11] around each of
9: the two sub-layers, followed by layer normalization [ 1]. That is, the output of each sub-layer is
10: LayerNorm(x + Sublayer(x)), where Sublayer(x) is the function implemented by the sub-layer
11: itself. To facilitate these residual connections, all sub-layers in the model, as well as the embedding
12: layers, produce outputs of dimension dmodel = 512.
13: Decoder: The decoder is also composed of a stack of N = 6 identical layers. In addition to the two
14: sub-layers in each encoder layer, the decoder inserts a third sub-layer, which performs multi-head
15: attention over the output of the encoder stack. Similar to the encoder, we employ residual connections
16: around each of the sub-layers, followed by layer normalization. We also modify the self-attention
17: sub-layer in the decoder stack to prevent positions from attending to subsequent positions. This
18: masking, combined with fact that the output embeddings are offset by one position, ensures that the
19: predictions for position i can depend only on the known outputs at positions less than i.

18: 3.2.3 Applications of Attention in our Model
19: The Transformer uses multi-head attention in three different ways:
20: • In "encoder-decoder attention" layers, the queries come from the previous decoder layer,
21: and the memory keys and values come from the output of the encoder. This allows every
22: position in the decoder to attend over all positions in the input sequence. This mimics the
23: typical encoder-decoder attention mechanisms in sequence-to-sequence models such as
24: [38, 2, 9].
25: • The encoder contains self-attention layers. In a self-attention layer all of the keys, values
26: and queries come from the same place, in this case, the output of the previous layer in the
27: encoder. Each position in the encoder can attend to all positions in the previous layer of the
28: encoder.
29: • Similarly, self-attention layers in the decoder allow each position in the decoder to attend to
30: all positions in the decoder up to and including that position. We need to prevent leftward
31: information flow in the decoder to preserve the auto-regressive property. We implement this
32: inside of scaled dot-product attention by masking out (setting to −∞) all values in the input
33: of the softmax which correspond to illegal connections. See Figure 2.
